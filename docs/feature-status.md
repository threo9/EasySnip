## 实现边界

- Windows 分享使用 Bitmap 格式，系统中能够接收图像的分享目标决定可用范围。
- GPU 配置用于画布预览，标注栅格化、高斯模糊和文件输出采用 CPU 图像合成。
- 元素匹配使用截图时记录的原生子窗口边界与已探测的 MSAA 层级，检测完整度取决于目标程序。
- HTML 贴图渲染剪贴板中的文字与基本富文本，外部 HTML 资源保持隔离。图片直链通过独立下载流程处理。
- 备份导入允许最多 10000 条记录，解码后的图像合计上限为 512 MiB。历史记录图像按需读取，日常历史浏览采用缩略图。
- 高级设置中的名称和行为对应 EasySnip 的实现。附件包含其他软件的对比措辞，具体交互以本工具为准。

## 验收记录

构建工具为用户指定的 Qt 5.14.2 / MinGW 7.3 64 位，使用 Release 优化构建。

已执行 38 项离屏自动回归检查和 46 项 Windows 原生环境检查。测试报告位于工作区 `test-results/results.json` 和 `test-results/native/results.json`。原生检查包括 GDI 桌面捕获、屏幕枚举、Qt 与 Win32 物理坐标一致性、全局热键注册释放、WinRT 分享准备、OpenGL 初始化、本机 HTTP 图片下载与大小限制。

完整应用流程测试通过主窗口命令打开图片，再点击编辑器“完成”按钮，验证同时复制图片和文件、自动保存、创建贴图、关闭贴图、恢复贴图及 HTML 剪贴板贴图。测试使用隔离目录，结束后恢复剪贴板数据。

便携包已在移除 Qt SDK 环境路径后通过同一套原生检查，另已验证单实例命令转发和 `--quit` 正常退出。报告位于 `test-results/package`。

自动测试用合成样例渲染历史管理界面和编辑器。真实目标程序的元素层级、混合 DPI 多显示器、系统剪贴板目标、打印机、开机启动和 Listary 属于人工集成验收范围。
