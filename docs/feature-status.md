# 功能覆盖对照

本文件对照用户提供的 `features.md` 与 `features-new.md`，区分实现范围和验证范围。功能清单中的“官方”描述保留为需求来源语境。EasySnip 的实现状态以本表、源代码和实际测试为准。

当前范围按用户最新要求调整为截图、标注与历史管理。贴图相关功能已移除，旧版图像按普通截图历史读取。

## 实现边界

- Windows 分享使用 Bitmap 格式，系统中能够接收图像的分享目标决定可用范围。
- GPU 配置用于画布预览，标注栅格化、高斯模糊和文件输出采用 CPU 图像合成。
- 元素匹配使用截图时记录的原生子窗口、UI Automation 和 MSAA 边界，后台查询限定到截图时的目标窗口。仅获取容器或遍历不完整时继续允许点位查询。检测完整度取决于目标程序。
- 备份导入允许最多 10000 条记录，解码后的图像合计上限为 512 MiB。历史记录图像按需读取，日常历史浏览采用缩略图。
- 高级设置中的名称和行为对应 EasySnip 的实现。附件包含其他软件的对比措辞，具体交互以本工具为准。
